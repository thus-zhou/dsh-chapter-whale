### P1 修复摘要

- **A 核心数据**：提交记录只认 `committed + 磁盘 sha + index current` 三重一致；导入回滚删除 commit 标记；拆分改为“先落后半章、再截断前半章”；保存前自动 `recover_pending`；删除/恢复索引读改写加版本锁；失效日志与 memory 加锁；合并失败回滚且可补删；`new_chapter` 使用 `expect_absent`；64-hex 版本必须属于本章；studio 润色改走 `commit_raw_bytes`。
- **B 批注/合并/Agent**：候选使用基准快照坐标；批内重叠 hunk 返回 `hunk_overlap`；提交正式版时 `mark_committed` 结算并清 `patch_ledger`；无草稿使用真实 `draft_epoch`；审批端点参数/项目校验修复；provider 回退按隐私域过滤；普通调用不再双预算。
- **C 平台/API**：GC 保护 artifact_refs、拒绝目录符号链接、移除 outline-backups；导出只允许项目外新 `.zip` 且原子写入；AI 提取强制 `ai_inferred`、高风险 `pending_confirm` 并提供确认/拒绝 API；任务 complete/fail 增加 running+owner 守卫；全站急停改为 manager 级文件并阻断 claim；`room_stream` 改 async + 项目过滤。
- **D 前端**：IME `force` 与 `composing` 复位；移动端浮条避让 dock、tab 5 列、触摸目标；面板 `beforeunload/visibilitychange` 落盘；textarea 焦点环；Ctrl+S 全局、抽屉滚动锁/aria、章节按钮 role、洞察失败提示、保存中反馈等。
