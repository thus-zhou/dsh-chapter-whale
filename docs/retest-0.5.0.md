# 0.5.0 界面更新验收

日期：2026-11-15，北京时间。

## 修改范围

- 将确认的玻璃工作台接入 DSH 原生插件，统一全站控件、字体、主题与阅读区域。
- 外观设置保存在本机：两套配色、明暗主题、三档炫彩和动效、减少动画、密度、黑体/宋体、遮罩和模糊。
- 工作台读取真实章节、用量与任务状态；按当前作品匹配任务，只采用当前章节的 A–E 请求阶段。
- 速度按已完成请求的输出 Token 与耗时显示；未知费用显示空缺，小额费用保留精度；没有历史参照或已超过参考用时时不显示虚假的剩余秒数。
- 更新 GitHub 文档和市场引用的九张正式界面截图，全部采用独立测试环境的示例数据。

## 本地检查

- Node 64 项通过，新增当前章节阶段、所选作品匹配、缺失费用与速度来源的回归检查。
- 真正 DSH 0.2.2-rc.1 独立 profile 中加载；原生模型服务列出两个测试模型，短请求连接探测通过。
- 测试作品正文、记忆和人物从本地管理 API 读取；没有真实模型调用或真实平台发布。
- 后端、Python 与 Chromium 内容未变，继续复用固定 0.4.2 运行时及摘要；不把本次界面检查表述为重新验收真实写作和发布质量。

发布包、公开下载与 CI 的最终结果在发布后补记。
