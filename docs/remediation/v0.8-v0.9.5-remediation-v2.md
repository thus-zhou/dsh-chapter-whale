- E-01：`writer_runner` 发布改走 `chapter_versions.commit_raw_bytes`，回执在版本提交成功后写，共用章锁；生成后 version/index/current_version 一致。

### 对抗复审新增的 P0/P1

- **B-09R-1**：纯删除记录原 `(start,end)`，部分重叠替换报 `overlap_conflict`，不再返回 `clean=True` 却吞正文；新增 20 字删除+替换回归。
- **A-R-01/02**：`recover_pending` 只有“正文从未由本次提交写入”才向前补齐；作者回退（`previous_sha` + done 含 chapter）或删除（current None）一律 `conflict`，不复活。
- **B-01R-1/2**：ledger 写基坐标，前缀插入后再采纳不再假冲突；章节级 preview 在生成时保存 base snapshot；`ledger`+`already_applied` 按 hunk/文本去重。
- **B-14R-1**：`BoundedBroadcaster` 只由 SSE generator 的 `ack()` 推进 delivered seq；溢出 marker 标 `full_reload`，不再以 enqueue seq 让客户端跳过积压。

- **D-09**：split/merge/restore 只要存在草稿就提示并阻止无提示删除；split 有草稿时要求先保存正式版本；草稿删除传真实 id，删除失败不 `skipDraft`。
- **D-14-K**：`visibilitychange` 改正常保存并 adopt 返回 revision；keepalive 只保留给 `pagehide`，避免下一次保存假冲突。
- **C-R2-01**：世界窗口关闭加 `subject`、只对 active 事实、保护 pinned/author_locked/confirmed 高权威，pending AI 候选不再关闭已确认事实。

- **C-R2-04**：`/api/jobs/{id}/run` 注入 `project_path`；`resume_due` 检查项目暂停。
- **X-P1-1**：最终代码冻结后重建 `runtime-manifest.json` 并同步 `runtime-download.buildId`；`backend/integration_data` 清理后 `check-release --local` 通过。
