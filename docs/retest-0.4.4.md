# 0.4.4 安装反馈修复与验证

2026-11-15，北京时间。针对安装后四项反馈完成以下修改。

| 反馈 | 修改 | 验证 |
| --- | --- | --- |
| 白框遮住文字 | 主按钮和选中密度控件使用成对的背景、文字色；下拉菜单使用不透明底色 | 白色强调色、透明背景的主题实测；主按钮对比度 6.18:1 |
| 插件异常、部分功能失败 | 工具改名 `chapter_whale`，避免与 `novel_helper` 冲突；路由随注入作用域回收；模型保存改用绑定接口，测试携带当前草稿和供应商版本 | 真正 DSH 宿主同时注册两个工具；绑定保存后重新进入保持模型与思考强度；六项连接探测通过 |
| 重复配置模型 | 从 DSH 模型服务获取可用目录，复用宿主适配器及登录状态；空配置自动选择宿主当前模型；提供通用模型和 A–E 继承、选择与刷新 | 通过 DSH 实际 LLM 服务调用测试适配器，覆盖文本、JSON、流式、工具调用；保留独立接口和已有绑定 |
| 注释性文案过多 | 精简首页、人物空状态、伏笔提示、AI 设置和插件管理说明 | 浏览器逐页查看并验证记忆和人物新增 |

模型桥仅监听本机随机端口，要求独立随机令牌，不读取或复制 DSH 的账号令牌。宿主负责鉴权、模型协议和请求；桥接覆盖工具历史、思考强度、用量和取消。模型终端失败不会将缓冲的半章作为成功正文返回。

## 验证结果

- Node 61 项、后端集成 277 项、管理端 83 项，共 421 项通过。
- DSH 0.2.2-rc.1 独立 profile 安装与运行；测试账号提供两个模型，另注册旧版工具名以复现共存场景。
- 自动选中宿主当前模型；A 角色改用第二个模型及 high 思考强度，保存并离开后重新进入，选择保持正确。
- 通用模型及 A–E 六项探测通过：A/D 为 JSON，B 为流式文本，C 为文本，E 为工具调用。
- 实际创建作品、共享记忆与人物；760px 视口无横向溢出，页面脚本异常 0。
- 本轮真实模型调用 0，真实章节发布 0。具体厂商账号的额度、生成质量和番茄发布效果未在本轮重新验收。
