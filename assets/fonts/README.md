# 界面字体来源

以下字体使用 SIL Open Font License 1.1。每份字体的完整版权与许可保留在对应的 `*-OFL.txt` 中。

| 源字体 | 来源 | 本机 CSS 名称 |
| --- | --- | --- |
| Manrope | https://github.com/google/fonts/tree/main/ofl/manrope | Whale Geometric |
| Noto Sans SC | https://github.com/google/fonts/tree/main/ofl/notosanssc | Whale Text |
| Noto Serif SC | https://github.com/google/fonts/tree/main/ofl/notoserifsc | Whale Editorial |

字体由 Google Fonts 官方仓库下载，按界面文本与 GB2312 常用字符做子集、修改字体内部名称并转成 WOFF2。宋体固定为 400 字重，另两份保留可变字重。常用简体字符由本机字体覆盖，其他字符使用系统回退。玛莎拉蒂与 Craft 的专有西文字体未复制或分发。
